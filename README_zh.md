## 名字

**Boreas** 是希腊的北风神。风从北方来，带着冷，带着噪音。**-ward** 是"朝……去"，像 northward、homeward。不是到了，是一直在去。

**Boreasward** 就是朝北风走。每一步都逆风。走到风的源头，才知道风为什么刮。

中文名 **溯风**（sù fēng）说的是同一件事。溯，是逆流而上，也是追溯、溯源。溯风，是顶着风走回风的来处。追溯来处，正是研究这件事的本质。

## 标志

一支朝北的箭穿过迎面的风。箭是 -ward。两侧的风线越靠近箭越短，是风被劈开、往两边散去。
